# Raport Koncowy Projektu (ISO 21513)

## 1. Cel Projektu
Stworzenie otwartej platformy EcoBook Hub laczacej dane o szkolach z dane.gov.pl z lokalna gielda podrecznikow.

## 2. Rezultaty
- Aplikacja Streamlit + DuckDB
- Integracja z rejestrem szkol z dane.gov.pl
- Repozytorium Open Source zgodne ze standardami

## 3. Porownanie z Planem
Projekt zrealizowany w 100% zgodnie z czasem i wymaganiami.

## 4. Wplyw Spoleczny
Oszczednosci dla domowych budzetow i wsparcie gospodarki obiegu zamknietego.
